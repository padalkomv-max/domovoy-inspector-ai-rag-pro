# Текстовое описание и голосовой ввод

Источник: исходный код «Домовой инспектор AI» (экспорт 09.11.2026)
Версия документа: 1.0
Статус: описание по коду, без подтверждения работоспособности в развёрнутой среде

## Описание
В поле «Описание проблемы» введите наблюдаемые факты: что произошло, где и когда. Не выдавайте предположения за установленные нарушения.

## Голосовой ввод
Рядом с полем описания предусмотрено управление голосовым вводом. Распознанный текст добавляется в описание. Работа зависит от поддержки браузером и разрешений на микрофон.

## Без изображения
Анализ возможен по одному текстовому описанию: сервер принимает запрос без фото при непустом description.

## Без данных
Если нет ни изображения, ни описания, запуск анализа блокируется в интерфейсе; сервер возвращает сообщение «Требуется фото или описание проблемы».
