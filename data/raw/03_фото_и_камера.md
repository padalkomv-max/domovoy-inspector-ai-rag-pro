# Добавление фотографии

Источник: исходный код «Домовой инспектор AI» (экспорт 09.11.2026)
Версия документа: 1.0
Статус: описание по коду, без подтверждения работоспособности в развёрнутой среде

## Загрузка файла
На вкладке «Фиксация» выберите способ загрузки с устройства; поле файла принимает изображения (image/*).

## Камера
Можно разрешить браузеру доступ к камере и сделать снимок. Используется браузерный API getUserMedia; для работы необходимы разрешение браузера и доступное устройство камеры.

## Ссылка
Можно вставить прямую HTTP(S)-ссылку на изображение. Сервер пытается скачать содержимое и проверяет, что тип ответа начинается с image/.

## Ошибки
Если URL не ведёт на доступное изображение, сервер сообщает «Ошибка загрузки фото по ссылке». При отказе в доступе к камере съёмка может быть недоступна. Для анализа можно использовать текстовое описание без фото.
