## Проверка поисковых механизмов

- **FAISS:** реальный `IndexFlatIP` по нормализованным embeddings `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`; в успешных API-ответах присутствовали 12 vector-результатов.
- **BM25:** реальный `rank_bm25.BM25Okapi`; в успешных API-ответах присутствовали 12 keyword-результатов.
- **RRF:** результаты объединялись через Reciprocal Rank Fusion с `k=60`; в LLM передавались 6 итоговых фрагментов с source/section/version.
- **Источники:** проверялись наличие ожидаемого документа и отображение source chips рядом с ответом.
- **Защита от выдумывания:** вопрос о стоимости подписки завершился отказом без подтверждённого фрагмента.

## Ограничение Gemini Free Tier

Во время частых последовательных реальных запросов Gemini вернул HTTP 429 `Too Many Requests`. Backend записал `provider_http_error` и вернул клиенту HTTP 502; это внешний лимит бесплатного тарифа, а не ошибка FAISS, BM25, RRF или JSON-парсера. После ожидания повторный запрос снова прошёл с HTTP 200. Платный API не подключался.

Из-за этого массовый прогон нельзя выполнять без пауз в пределах одного rate-limit окна. Это ограничение тестовой квоты Gemini, сохраняющееся без дополнительной настройки тарифа/лимитов.
